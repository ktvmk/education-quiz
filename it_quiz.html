データの単位

ビット（bit）：0か1の1桁分。情報の最小単位。
バイト（Byte）：8ビット = 1バイト。半角英数字1文字分。
nビットで表せる状態数 = 2n
1ビット→2通り / 8ビット→256通り / 32ビット→約43億通り
K=約1,000 / M=約100万 / G=約10億 / T=約1兆

基数変換

10進数：0〜9を使う / 2進数：0と1だけ / 16進数：0〜9＋A〜F
2進数→10進数：各桁×2nをたし合わせる
例）1011 = 8+0+2+1 = 11
10進数→2進数：2で割り続けて余りを下から読む
例）22÷2=11余0, 11÷2=5余1, 5÷2=2余1, 2÷2=1余0, 1÷2=0余1 → 10110
2進数↔16進数：4桁ずつ区切って変換
例）10110100 → 1011|0100 → B4

負の2進数とシフト演算

2の補数：①全ビット反転 → ②+1 で負の数を表す
先頭0=正、先頭1=負
左1シフト = ×2 / 右1シフト = ÷2
論理シフト：符号なし / 算術シフト：符号ビット固定
頻出：「xを2ビット左シフトしてxを加える」→ x×4+x = 5x

論理回路と加算回路

論理演算を電子回路で実現→論理回路（MIL記号で表記）
半加算器= XOR＋AND（桁上がり考慮なし）
全加算器= 半加算器×2＋OR（桁上がり考慮あり、入力3つ）
オートマトン：入力→状態→出力 でシステムをモデル化
状態遷移図：円=状態、矢印=遷移
